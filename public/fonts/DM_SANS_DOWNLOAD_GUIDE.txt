DM Sans Font Download Guide
===========================

To complete the local font setup, you need to download the DM Sans font files:

1. Visit the official source:
   - Google Fonts: https://fonts.google.com/specimen/DM+Sans
   - GitHub (Official): https://github.com/googlefonts/dm-fonts

2. Download the following font weights in WOFF2 and WOFF formats:
   - DMSans-Light (300)
   - DMSans-Regular (400)
   - DMSans-Medium (500)
   - DMSans-SemiBold (600)
   - DMSans-Bold (700)
   - DMSans-ExtraBold (800)

3. Place the downloaded files in this directory (/public/fonts/)

4. File naming should match:
   - DMSans-Light.woff2 / DMSans-Light.woff
   - DMSans-Regular.woff2 / DMSans-Regular.woff
   - DMSans-Medium.woff2 / DMSans-Medium.woff
   - DMSans-SemiBold.woff2 / DMSans-SemiBold.woff
   - DMSans-Bold.woff2 / DMSans-Bold.woff
   - DMSans-ExtraBold.woff2 / DMSans-ExtraBold.woff

Alternative: Use a webfont generator
   - Visit: https://transfonter.org/
   - Upload the TTF/OTF files
   - Select WOFF2 and WOFF formats
   - Download and rename according to the pattern above

The @font-face declarations are already set up in index.css!
